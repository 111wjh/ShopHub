# ShopHub 界面截图

以下图片直接截取自本仓库现有 Vue 页面，展示深色科技主题、购物流程和管理端布局。商品名称、插画、价格、库存、账号及订单均为隔离环境中的示例数据，不对应真实商品或交易；截图过程没有修改原后端或数据库。

## 商城首页

商品卡片、分类入口、价格、现货状态及缺货状态。

![商城首页](home-desktop.jpg)

## 商品详情

商品图片、说明、库存、数量选择及加入购物车入口。

![商品详情](product-detail.jpg)

## 购物车

多商品明细、购买数量、单价、小计与订单总金额。

![购物车](cart.jpg)

## 订单列表

按订单状态筛选，展示订单编号、金额和详情入口。

![订单列表](orders.jpg)

## 订单详情

订单状态进度、金额、商品快照及待支付订单操作。

![订单详情](order-detail.jpg)

## 登录

账号表单与统一导航。图片中使用截图专用示例账号，不提供公开测试账号。

![登录页面](login.jpg)

## 商品管理

管理员查看商品列表、库存与上架状态，并进入新增或编辑操作。

![商品管理](product-manage.jpg)

390 像素宽度下的商城页面与购物车。长页面保留完整内容，点击图片可查看原图。
